# Savr v1.3.2

## What's new

### Bookmark editing & saving

- **Edit bookmarks** — open any bookmark in a full-screen live-preview editor and update its title, description, and metadata on the spot.
- **Clipboard URL detection** — copy a link anywhere and Savr offers to save it instantly, with a suggestion sheet that lets you preview before adding.
- **Skip duplicate saves** — paste an already-saved link and Savr recognizes it instead of creating a copy.
- **Quick save for shared links** — share a URL to Savr from any app to save it fast, with improved metadata fetching.

### Themes

- **AMOLED theme** — true-black surfaces that save battery, while keeping Material You dynamic colors.
- **Better AMOLED contrast** — raised card surfaces and an always-visible dynamic color option.

### Updates

- **In-app update checker** — Savr now checks for a newer version on GitHub and offers to download and install it right from Settings.
- **Redesigned app update icon** — a cleaner refresh-style icon for the in-app update checker.

## What's fixed

- Bookmarks disappearing from collections when multiple collections were involved; queries now re-emit consistently on cross-reference changes.
- Add-bookmark button staying active while metadata was still loading.
- Theme text legibility in the edit bookmark sheet and bookmark cards.
- Minor stability improvements.

## Files

- `app-release.apk` — signed installable APK (GitHub direct downloads)
- `app-release.aab` — signed App Bundle (for the Play Store)
